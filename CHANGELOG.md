# Change Log

All notable changes to the "quiklog" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [vscode-v1.3.0] - 2026-05-24

### Added

- Smart insert: log statements now insert after closing bracket when cursor is inside destructuring or object patterns

### Changed

- Refactored language templates to a map structure for easier maintenance
- Added `feature` as recognized language ID for Gherkin files

## [intellij-v1.1.0] - 2026-05-24

### Fixed

- Plugin now compatible with IntelliJ 2026.x (removed untilBuild restriction)

### Added

- Smart insert: log statements now insert after closing bracket when cursor is inside destructuring or object patterns

### Changed

- Refactored language templates to a map structure keyed by file extension

## [vscode-v1.2.3] - 2026-02-20

### Changed

- Fixing gif display issue

## [vscode-v1.2.2] - 2026-02-20

### Changed

- Removed VS Code files from root `.gitignore`
- Updated `vscode/README.md` for clearer instructions and screenshots

## [vscode-v1.2.1] - 2026-02-22

### Changed

- Updated README to clarify macOS keyboard shortcut (Cmd+Option instead of Alt)

## [intellij-v1.0.2] - 2026-02-10

### Changed

- Enhanced plugin description with usage instructions and keyboard shortcuts
- Improved marketplace listing with detailed feature list

## [intellij-v1.0.1] - 2026-01-19

### Added

- IntelliJ IDEA plugin released
- Same features as VS Code extension

## [v1.2.0] - 2026-01-14

### Fixed

- Gherkin language ID now recognized for .feature files

### Added

- Support for C language with printf statements
- Support for C++ language with std::cout
- Support for C# language with Console.WriteLine

## [v1.1.0] - 2025-10-16

- Added support for JSX and TSX files
- Cursor detection for variables (no selection required)
- Improved snippet indentation
